# chippie - A CHIP-8 interpreter

*chippie* is a CHIP-8 interpreter written in C++ using Raylib for the frontend.

*chipc* is an assembler for creating CHIP-8 programs. Refer to `ASSEMBLER.md` for the instruction set.

## Build

All that is required to build is CMake and a C++ compiler supporting C++23.

```bash
cmake -B build
cmake --build build
```
